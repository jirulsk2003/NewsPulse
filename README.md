# 📰 NewsPulse

> A modern and responsive news application for discovering and reading news content.

## 📌 About The Project

**NewsPulse** is a web-based news application developed as a personal project.

The application provides a clean and user-friendly interface for browsing news content. It focuses on responsive design, dynamic content handling, and a simple reading experience.

## ✨ Features

- 📰 Browse news articles
- 🔎 Search news
- 📂 News categories
- 🖼️ News cards with images
- 📄 Article information
- 📱 Responsive design
- ⚡ Dynamic news content
- 🎨 Clean and modern UI
- 🌐 API-based news data

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- JSON
- Responsive Web Design
